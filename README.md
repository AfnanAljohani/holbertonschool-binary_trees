# C - Binary Trees

This project contains tasks about binary trees in C.

## Description

A binary tree is a tree data structure in which each node has at most two children, referred to as the left child and the right child.

## Files

The project contains files from 0-binary_tree_node.c to 18-binary_tree_uncle.c implementing various binary tree operations.

## Compilation

All files are compiled with: gcc -Wall -Werror -Wextra -pedantic -std=gnu89
